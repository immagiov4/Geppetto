# Classifier evaluation proposal

Compare each optional classifier with the project's existing routing and retrieval, using the user's approved models and scope. Discover existing hooks, global jobs, credential sources and invocation policy before proposing configuration changes. Reuse an equivalent configured integration; identify actual runtime enablement separately from the presence of files.

## Observability

- Skill selection: compare the existing catalog/router with request-specific suggestions. Include useful-but-unused and explicit-only skills, ambiguous requests and requests requiring no skill. Measure suggested skill relevance, omissions, unnecessary activations, actual injected context, added latency and provider-reported cost. Suggestions alone do not suppress a host catalog.
- Memory retrieval: compare direct index navigation with recursive suggestions on shallow, nested, branching and irrelevant topics. Include a large index requiring request splitting. Measure terminal-page relevance, missed branches, model calls, exact request bytes, injected bytes, end-to-end latency and cost.
- Requirements screening: compare ordinary source search/caller tracing with ranked reading targets on the same approved repository questions. Measure useful paths found and missed, irrelevant targets, added latency, context and cost; source reading remains authoritative.

Use synthetic public fixtures first. Match inputs, source revisions, selected model, concurrency and request limits between comparisons. Record failures separately and inspect the final outcome as well as intermediate suggestions. Human-only setup can be generated dynamically with an existing Wizard or completed through the host's private secret facility. Reuse a key already available to the actual hook process; a file containing a key is not proof that the process loads it.

This document prepares the requested comparison. Paid calls require the existing authorization and a bounded reservation; permanent activation follows the separate keep decision. The project's classifier remains disabled while those decisions are pending.
