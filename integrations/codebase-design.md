# Codebase Design

Skills: codebase-design

Strongly suggested for design. [Codebase Design by Matt Pocock](https://github.com/mattpocock/skills) supplies a shared vocabulary for deep modules: substantial behavior behind a small interface, at a boundary that can be tested through that interface.

Status: recommended from the maintainer's workflow; comparative benefit is still being evaluated.

## Install

Reuse the installed skill. Otherwise select `codebase-design` from `mattpocock/skills` with the harness's skill installer, or run `npx skills add mattpocock/skills --skill codebase-design`.

## With geppetto-spec

Use it to reason about module responsibility, interface depth and the seam where behavior and diagnostics belong. Combine it with Architect's concrete sketches rather than creating a second design process.
