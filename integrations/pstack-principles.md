Status: optional; select by the unresolved concern rather than loading the collection by default.

## Install

Use the harness's installer to select the relevant `principle-*` skills from `cursor/plugins`, path `pstack/skills`, or reuse compatible installed copies. Preserve the original license and the project's invocation preferences.

## With geppetto-spec

Use a principle when it resolves a concrete design concern not already covered by the active procedures. Architect and Codebase Design remain the primary recommended design companions.

## With geppetto-build

Select applicable principles without duplicating the project's existing checks or loading unrelated guidance.
