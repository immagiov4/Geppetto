# Project hooks

`SessionStart` runs `memory-hook.mjs` to expose the configured memory location, every root-index bucket description and the full indexes of linked nonprivate buckets. Project `.geppetto/config.json` overrides `~/.geppetto/config.json`; choose linked buckets with `memory.buckets: ["nous", "geppetto"]`. Legacy `projectBucket` is accepted as a one-element list. Pages and the private bucket's index stay outside hook context. Missing clones produce one reasoned unavailable line. Each injection records its UTF-8 byte count in `.geppetto/hook-events.jsonl`.

The same memory hook runs on `UserPromptSubmit`. Optional `hooks.memoryClassifier` defaults to `{ "enabled": false, "benchmark": null }`. Enable it only after the semantic-hook benchmark/keep decision and a standing user/project `memory-classifier` grant. Obtain its OpenRouter key through the harness secret store and expose it as `OPENROUTER_API_KEY` in the hook environment; credentials stay outside configuration. User-level classifier settings are overridden by project settings.

An enabled classifier requires owner-selected `model`, `bucketThreshold` and `pageThreshold` (inclusive scores in [0, 1]), `timeoutMs` (the combined two-stage deadline), `maxOutputTokens` (per request), and `maxCostUsd` (the bounded maximum reserved for both requests). Choose the deadline below the enclosing hook's `timeout` in seconds, leaving room for ledger operations and local reads; increase that enclosing timeout when the authorized selection budget needs it. This package supplies no calibrated model or score threshold. Benchmark selection quality, injected bytes, elapsed time and cost before keeping these settings. [OpenRouter's API](https://openrouter.ai/docs/api_reference/overview) and [structured outputs](https://openrouter.ai/docs/guides/features/structured-outputs) define the adapter contract.

Stage one receives the current question and descriptions of global buckets plus linked project buckets, with the private bucket excluded. Stage two receives only page links/descriptions from selected bucket indexes. Page bodies stay on disk. Returned IDs must belong to these candidate lists; output is a short list of suggested paths and one-line reasons. Timeouts, invalid responses, provider errors and authorization failures emit no suggestions and append a redacted error with zero injected bytes. Every run logs provider-call count, duration, actual known cost and injected bytes. Known charges settle in the shared ledger; unknown charges retain the full reservation for reconciliation. Keep actual provider spending caps configured separately from the consent ledger.

Merge `claude/settings.json` into `.claude/settings.json` and `codex/.codex/hooks.json` into `.codex/hooks.json`, retaining existing hook entries. Each command finds `.geppetto/bin/hook.mjs` from the working directory's ancestors and launches it with the current Node executable and hidden subprocess windows. Run each exact command from a nested project directory and review/trust the resulting configuration in the harness. Record the complete merged files with `install.mjs --record-generated` after the owner-approved migration.

`UserPromptSubmit` delimits turns, `PreToolUse` counts tool calls and provides PR/authorization feedback, and `Stop` requests a single learning judgment after a long turn. Defaults in `.geppetto/config.json` are `hooks.learnNudge: { "enabled": true, "benchmark": null, "minToolCalls": 20, "minDurationMs": 300000 }`. Either threshold qualifies: twenty calls captures tool-heavy work, while five minutes since the first tool captures a long command. These initial, configurable noise filters are design choices rather than calibrated quality claims. Short turns start their counts afresh; one firing per session bounds added context. Set `enabled` to false to decline this deterministic reminder independently of paid semantic hooks.

Stop returns `decision: "block"` with one short reason, the documented continuation protocol for [Claude Code](https://code.claude.com/docs/en/hooks#stop) and [Codex](https://learn.chatgpt.com/docs/hooks). The handler itself makes zero model calls and needs no key; the continuation consumes the active session's ordinary model context. `stop_hook_active` and a session marker prevent recursive reminders. Each firing appends its session hash, time, call count, elapsed time and handler cost to `.geppetto/hook-events.jsonl`; activity stays in ignored `.geppetto/hook-state/`. Compare firings with `.geppetto/signals.jsonl` for yield, and include actual continuation usage when measuring total cost. Handler tests establish the protocol and logs; actual harness loading and trust require a fresh-session check.
