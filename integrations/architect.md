# Architect

Skills: architect

Strongly suggested for non-trivial design. [Architect from pstack](https://github.com/cursor/plugins/tree/main/pstack/skills/architect) grounds the existing system, compares designs and settles caller usage, types and responsibilities before code.

## Install

Reuse the installed `architect` and its dependencies. Otherwise use the harness's skill installer with `cursor/plugins`, path `pstack/skills/architect`, preserving its license and resolving the skills it calls. Use a compatible local adaptation when the original's tools are harness-specific.

## With geppetto-spec

Use Architect for competing caller-usage and module sketches before implementation. Keep the agreed design checkpoint. Include the technical observation points defined by geppetto-x-ray in that design.
