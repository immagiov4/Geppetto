# Background learning

`learn-runner.mjs` reads new records from the project's ignored `.geppetto/signals.jsonl`, takes `~/.geppetto/learn.lock` and creates a Git worktree branch under `~/.geppetto/worktrees/`. It freezes current permitted project files, including staged and unstaged changes, new non-ignored files and deletions, through a separate Git index. The user's index and working files stay intact. Private paths, credentials and harness configuration retain the file tool's exclusions. The lock covers capture, the CLI call and finalization across every project on the machine. Successful runs save the last consumed signal in `.geppetto/learning.json`; failure retains the signals for another run.

The state records `sourceHead`, the captured `baseline`, and `excludedChanges` for changes outside the permitted file scope, including submodule contents that are not copied into the learning worktree. A snapshot commit contains the input project state; review the learner's improvement with `git diff <baseline> <branch>`. The final learning commit contains only changes made after that baseline. Integrate that improvement against the current project state, preserving work performed since capture.

The runner starts `codex exec` or `claude -p` with a fixed learning prompt. Set `hooks.signalLearning.model` when a task requires a particular model; Codex also accepts `hooks.signalLearning.reasoningEffort`. These selections are passed explicitly because the isolated child does not load the caller's configuration. Without a selection, the child uses its CLI default. The prompt names the installed `geppetto-learn` procedure; Read can access that package's bundled procedures and references, while Write and Edit remain confined to project files. API-key routing is removed from the subscription child's environment. Only bounded Read, Write, Edit, Glob and Grep tools are exposed through `learner-tools.mjs`: **no shell, delegation or push**. The adapter excludes private buckets, credentials and harness configuration. The parent stages validated paths and creates the local commit. `hooks.signalLearning.writeApproval: true` leaves changes staged for review; the default is false.

The Stop hook invokes the runner asynchronously. `hooks.signalLearning.enabled: false` disables it. Inspect `.geppetto/hook-events.jsonl` for the outcome and worktree location. A failed run leaves its worktree for inspection. If a process was killed, verify its recorded PID has exited before removing a stale machine lock.
