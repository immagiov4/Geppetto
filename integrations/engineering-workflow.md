# Engineering Workflow

Skills: engineering-workflow

Suggested as the execution router when the project needs one. [Engineering Workflow](https://github.com/immagiov4/my-codex-skills/tree/main/skills/engineering-workflow) connects discovery, architecture, implementation, verification and documentation; Geppetto supplies the conditions for inspecting and improving that work.

## Install

Reuse the project's or harness's installed `engineering-workflow`. Otherwise select it from `immagiov4/my-codex-skills` with the harness's skill installer, or run `npx skills add immagiov4/my-codex-skills --skill engineering-workflow`. Resolve its referenced skills and record source and scope in `packs`.

## With geppetto-spec

Follow the workflow's discovery and design route, strongly suggesting Architect and Codebase Design at that stage. Settle technical observability in the specification before implementation and choose documentation structure separately from prose style.

## With geppetto-build

Use the selected workflow for execution while retaining the approved behavior, diagnostics and independently verifiable units.
