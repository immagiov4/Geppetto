# Maintain memory

Use $geppetto-memory to maintain the nonprivate buckets of the machine memory repository. Keep generalizable lessons and decision rationale: consolidate events into lessons, merge duplicates, drop material held by another owner, reconcile contradictions and repair indexes. Search with `rg`; `git log -p <page>` shows why a fact changed. Verify local changes and retain them for review.

Run processes through the process-execution reference. Report the inspected scope, useful changes and verification result.
